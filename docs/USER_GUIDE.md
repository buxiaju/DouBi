# DouBi 用户手册

> 给装了 DouBi 的 Windows 用户。
> 这不是开发文档、不是 CLI 文档——目标是从「双击 exe」到「下完第一个视频」的 5 分钟路线图，加上日常会用到的高频操作。
>
> 看完本手册能完成的事情：
>
> - 复制一个视频链接，把它下到本地
> - 搜索「Python 教程」一次性下完前 20 个视频
> - 登录抖音 / B 站，下登录后可见的高画质视频
> - 换主题、换语言、换下载目录、改文件名格式
> - 任务暂停 / 重试 / 取消 / 重新下载
> - 出问题能找到日志、能把诊断包发给作者
> - 卸载时知道哪些会被清、哪些会被留

---

## 1. 装完第一件事

### 双击「豆比」图标启动

装好后开始菜单和桌面上都有「**豆比**」图标（`doubi-gui.exe`）。双击启动后，第一次会闪一下启动屏，然后主窗口出现在屏幕中央。

> **首次运行「翻译正常」自检 2 条**（10 秒确认包是好的）：
>
> 1. **标题栏**应为「**豆比下载 <版本号>  ·  多平台视频下载器 - DouBi**」。如果看到的是 `app.title_suffix` 这种英文 key → 包坏了，重新下。
> 2. **左侧导航**从上到下应为「**解析 / 下载 / 历史 / 设置**」（0.3.3 起加的「搜索」「热榜」两项可能在下面，也正常）。如果看到 `nav.parse` / `av.downloads` 这种英文 key → 包里的 i18n 资源没打进去，重新下。

![启动界面](screenshots/00_doubi_037_startup.png)

### 默认下载目录

第一次启动时程序不会创建下载目录——下载第一个任务时才会建。**默认目录**：

```
%USERPROFILE%\Downloads\DouBi\
```

如果你想换目录，去「设置」页改「下载目录」字段，点「保存设置」即生效（详见 [§6 设置详解](#6-设置详解)）。

### 关窗不退出，最小化到托盘

第一次点右上角 × 关闭窗口时，会弹一个说明：「**DouBi 默认不退出，最小化到系统托盘**」——这是有意的行为，下载到一半关窗不会丢任务。想真退出走托盘菜单（见 [§8 托盘](#8-托盘)）。

## 2. 下第一个视频

5 步走完第一次下载：

### 步骤 1：复制链接

去抖音 / B 站 / YouTube 找你要下的视频，**复制浏览器地址栏的 URL**。不用进视频页点分享——地址栏的 URL 就够。

各平台都认的链接形态（举例）：

| 平台 | 链接示例 |
|---|---|
| 抖音单条 | `https://www.douyin.com/video/7123456789012345678` |
| 抖音 modal 链接（信息流弹窗） | `https://www.douyin.com/jingxuan?modal_id=7123456789012345678` |
| 抖音合集 | `https://www.douyin.com/collection/7647083357288957995` |
| 抖音用户主页 | `https://www.douyin.com/user/MS4wLjABAAAAxxxx` |
| B 站单条 | `https://www.bilibili.com/video/BV1xx411c7mD` |
| B 站用户主页 | `https://space.bilibili.com/123456` |
| B 站收藏夹 | `https://www.bilibili.com/favlist?fid=999` |
| B 站稍后再看 | `https://www.bilibili.com/watchlater` |
| YouTube watch | `https://www.youtube.com/watch?v=dQw4w9WgXcQ` |
| YouTube 短链 | `https://youtu.be/dQw4w9WgXcQ` |

抖音 modal 链接、用户主页合集 tab 复制的链接、APP 分享的链接——**都自动识别**，不用手动改。

### 步骤 2：粘贴到「解析」页

主窗口默认就是「解析」页：

![解析页（豆比紫主题）](screenshots/01_parse_doubi.png)

把链接粘到顶上的输入框，点**解析**按钮（或「快速下载」——直接解析并入队，省一步）。

### 步骤 3：勾选要下的行

解析完成后中间会出现一个表格。**默认全选**——你只要点**下载选中 (N)** 按钮就完事。

如果你下了个合集、用户主页、收藏夹——表格会有几十上百行，用**顶部搜索框**按标题 / 作者过滤，或者用「按行号选择…」填 `1-5,7,9-12` 这种范围表达式。

> **B 站三层结构**：合集 → 分类 → 分集 → 分P。表格默认只显示第一层；**右键点分类行 → 展开分类 / 折叠分类**，再右键点分集行 → 展开分P / 折叠分P，逐层展开。容器行（分类 / 分集）勾选框不可点——必须先展开再勾下面的视频行。

### 步骤 4：点「下载选中 (N)」

按钮文字会显示当前勾选数。点一下任务就入队，自动跳到「下载」页开始跑。

### 步骤 5：去「下载」页看进度

![下载页](screenshots/02_download_doubi.png)

每行最右是「暂停 / 继续」按钮（**文案表达下一步动作**——正在下载显示「暂停」、已暂停显示「继续」）。顶部有「全部暂停 / 全部继续」一键控制。

下载完成的文件去了哪？见 [§9 数据位置](#9-数据位置)。

### 副流程：批量下载怎么快

- 想下「**所有相关 Python 教程视频**」——去「搜索」页（见 [§3 批量下](#3-批量下)）
- 想下「**热搜榜上的视频**」——去「热榜」页
- 想下「**某个 UP 主所有投稿**」——粘主页链接到解析页

## 3. 批量下

DouBi 内置**搜索页**和**热榜页**——不用挨个复制链接。

### 3.1 搜索页

![解析页（浅色）](screenshots/05_parse_light.png)

1. 顶部平台 Tab 选「**抖音**」或「**B 站**」
2. 搜索框填关键词，回车
3. 结果表会列出 20 条命中——按 Tab 类型分（抖音：综合 / 视频 / 用户 / 直播；B 站：视频 / 用户）
4. 行右键菜单：
   - 视频行：**下载** / **复制链接** / **在浏览器中打开**
   - **热搜词行**（只有词，没链接）：**「搜索该词并下载全部视频」**——点一下会先搜再弹框告诉你「共搜到 N 个视频」，确认后全部入队
   - 用户行（`media_type=USER`）：右键会先弹确认框告诉你「这是 UP 主主页，会展开成全部投稿」，确认后入队

> **抖音搜索可能返回 0 条**：抖音搜索类接口在**未登录**时返回 403 或风控门 `verify_check`。这是平台侧的限制，客户端没法绕过——想搜抖音内容先在设置页完成抖音登录。

### 3.2 热榜页

跟搜索页类似，平台 Tab 选「**抖音**」或「**B 站**」就能看到对应平台的热点榜。抖音 4 牌榜：热搜 / 娱乐 / 社会 / 挑战；B 站：热搜词 + 热门视频。

**右键热搜词行 → 「搜索该词并下载全部视频」**——和搜索页词条行是同一行为，先搜再确认。

### 3.3 解析页批量入队

如果你**已有 URL 列表**（比如从收藏的 txt 里来），直接粘到解析页输入框（多行）——每行一个 URL，点「解析」会一次性解析全部，勾选 + 入队。

## 4. 登录抖音 / B 站

下载公开内容不需要登录。但**很多功能需要登录态**：

| 能力 | 需要登录 |
|---|---|
| 抖音搜索 / 收藏夹 / 评论 | ✓ 抖音 |
| B 站搜索 / 收藏夹 / 1080P 以上画质 | ✓ B 站 |
| 单条公开视频 / 合集 / 用户作品列表 | ✗ |

### 登录路径

设置页 → 「**账号**」卡片 → 点「**登录抖音**」或「**登录 B 站**」：

![登录 B 站](screenshots/15_login_bilibili.png)
![登录抖音](screenshots/16_login_douyin.png)

弹窗里会**自动弹一个浏览器窗口**（程序内置 Chromium），打开抖音/B站登录页——**在那个窗口里扫码 / 输账密**就行。登录成功后程序自动抓 cookies 存到本地，关闭浏览器即可，**全程不需要手动复制 cookies**。

### 登录态存在哪

`%USERPROFILE%\.doubi\cookies\<platform>.txt`——Netscape 格式，**只本机使用**（程序不会上传到任何服务器）。

### 想看登录状态

设置页 → 「账号」卡片会显示当前是否登录 + 上次登录时间。CLI 也可：`doubi auth status`。

## 5. 主题 + 语言

### 5.1 主题

DouBi 内置 **7 套主题包**，每套是一整张配色表（背景 / 文字 / 表格斑马纹 / 状态色 / 进度条），不是简单的明暗开关。

| 主题 | 适合 |
|---|---|
| `default_light` 默认亮 | 默认；日常光线 |
| `default_dark` 默认暗 | 夜间 |
| `doubi` 豆比紫 | 品牌主题（深紫底 + 琥珀橙主色） |
| `deep_sea` 深海 | 夜间，偏冷色 |
| `morandi` 莫兰迪 | 低饱和，久看不累 |
| `eye_care` 护眼 | 长时间盯屏 |
| `high_contrast` 高对比 | 弱视 / 强光环境 |

![默认亮](screenshots/02_default_light.png)
![默认暗](screenshots/03_default_dark.png)
![豆比紫](screenshots/01_doubi.png)
![深海](screenshots/04_deep_sea.png)
![莫兰迪](screenshots/05_morandi.png)
![护眼](screenshots/06_eye_care.png)
![高对比](screenshots/07_high_contrast.png)

**三种切换方式**：

| 方式 | 立即生效 | 是否记住 |
|---|---|---|
| 设置页「主题：」下拉框 | 是（选中即预览） | **点「保存设置」才写入配置** |
| 左侧导航栏最下方的画笔按钮 | 是，每点一次循环下一套 | 否，重启后回到配置里的主题 |
| 启动参数 `--theme deep_sea` | 是 | 否，只影响本次启动 |

**要想固定**：走设置页 + 点「保存设置」。画笔按钮和 `--theme` 都只是临时试色。

主题切换是**全局立即生效**——已打开的表格 / 卡片 / 下拉框、以及之后新建的对话框 / 右键菜单都会一起变色，**不需要重启**。

### 5.2 语言

设置页「外观」卡片 → 「语言」下拉框（简体中文 / English）。**选完点「保存设置」，重启应用后生效**——已渲染的控件不会自动重译。语言属于「重启生效」档。

## 6. 设置详解

设置页有 6 张卡片。**改完必**点底部「**保存设置**」——只在下拉框点是不会落盘的。

![设置页](screenshots/04_settings_doubi.png)

### 6.1 下载

| 项 | 默认 | 说明 |
|---|---|---|
| **下载目录** | `%USERPROFILE%\Downloads\DouBi` | 任务开始时若不存在则结果为空串。**绝对路径**与**留空**会被特殊处理：留空 = 关数据库 / 关清单。 |
| **目录模板** | `{platform}/{author}/{media_type}` | 还原平台 / 作者 / 媒体类型三层结构。详见下表。 |
| **文件名模板** | `{title}_{item_id}` | `{title}` 是每个视频自己的标题。 |

**模板可用的字段**（从单条视频元数据派生）：

| 字段 | 例 |
|---|---|
| `{platform}` | `douyin` / `bilibili` / `youtube` |
| `{author}` | UP 主名 / 抖音作者 |
| `{media_type}` | `video` / `audio` / `image` |
| `{title}` | 视频标题（自动去 Windows 非法字符） |
| `{item_id}` | `BV1xx411c7mD` / `7123456789012345678` |
| `{upload_date}` | `20240825` |

### 6.2 画质 / 格式

| 项 | 默认 | 说明 |
|---|---|---|
| **画质** | `best` | 选 `1080p` / `4k` 等固定档位，**登录后才能拿到**高清画质 |
| **容器** | `mp4` | 也可 `mkv` / `webm` |

### 6.3 附加下载（侧车文件）

| 项 | 说明 |
|---|---|
| `.nfo` 元数据 | Kodi / Jellyfin 可识别的元数据 |
| 字幕 | yt-dlp 自动 + 手动字幕（产出 `.vtt`） |
| 弹幕（B 站） | 分P级 `.xml`，不走 yt-dlp |

### 6.4 限速 / 代理

| 项 | 格式 | 说明 |
|---|---|---|
| **限速** | `5M` / `1000K` | 例 `5M` = 5 MB/s，`1000K` = 1000 KB/s。空 = 不限。 |
| **代理** | `http://127.0.0.1:7890` | HTTP 代理。空 = 直连。 |

### 6.5 通知

下载完成时的系统通知三档可选：

| 档 | 行为 |
|---|---|
| `success`（默认） | 只在任务成功时弹 |
| `all` | 成功 + 失败都弹 |
| `summary` | 单任务静默，整个队列跑完时弹一次 |

### 6.6 行为

| 项 | 说明 |
|---|---|
| **断点续传** | 默认开。下到一半关了再开会从 `.part` 位置继续，不重来。 |
| **跳过历史记录** | 关掉就不写 `~/.doubi/doubi.db`（不会显示在「历史」页） |
| **跳过下载清单** | 关掉就不写 `~/.doubi/download_manifest.jsonl` |

### 6.8 账号（详见 [§4 登录抖音 / B 站](#4-登录抖音--b-站)）

## 7. 任务管理

### 7.1 下载页

![下载页](screenshots/02_download_doubi.png)

每行最右是「暂停 / 继续」按钮——**文案表达下一步动作**：

| 当前状态 | 按钮文案 | 点下去 |
|---|---|---|
| 正在下载 | 「暂停」 | 进入 `pausing` 状态，几秒后变 `paused` |
| 已暂停 | 「继续」 | **断点续传**从 `.part` 位置接着下，不重来 |
| 已完成 / 失败 | 隐藏 | （占位宽度不变，表格不跳列） |

顶部有「**全部暂停** / **全部继续**」一键控制：只要还有正在下载的，**一律显示「全部暂停」**；全部暂停后才切到「全部继续」。混合列表不会"暂停一批又恢复另一批"。

顶部摘要：「**N 个正在下载，M 个已暂停**」。

### 7.2 三种任务"重做"入口

任务出问题时，右边会变成对应的"重做"按钮：

| 状态 | 按钮 | 行为 |
|---|---|---|
| 下载失败 | 「重试」 | 重新解析 + 入队 |
| 已取消 | 「重试」 | 同上 |
| 已完成但文件被删 | 「**重新下载**」 | 不重新解析，原任务直接重排进队列——和「重试」区分开，按钮文案不一样 |

「**重新下载**」的存在是因为：完成的任务可能是很久之前的，重新解析可能元数据已变（标题改了、合集删了视频）；直接重排能保证**文件名 / 目录都和原来一致**。

### 7.3 删除任务

左侧的「**移除**」按钮——从列表拿掉任务并删除未完成的 `.part` 文件。**暂停是保留文件等待继续**，和删除是两码事。

### 7.4 取消正在排队的任务

下载页右上有「**清空已完成**」按钮，一键清掉所有已完成任务的显示。**「清空全部」**会把所有任务（无论状态）从列表移除——但**不会删磁盘上的文件**。

## 8. 托盘

关窗不退出，程序在系统托盘（屏幕右下角）继续跑。托盘图标右键四项：

| 项 | 行为 |
|---|---|
| 显示主窗口 | 把主窗口拉到最前 |
| 全部暂停 | 等同于下载页「全部暂停」 |
| 全部继续 | 等同于下载页「全部继续」 |
| **退出** | 真退出程序——**这是真退出的唯一入口**（点右上角 × 只是最小化）

> 想真退出，必须走托盘菜单「退出」。这点第一次关窗时会有提示，第二次之后就不再提示了。

## 9. 数据位置

所有 DouBi 的数据都在 `%USERPROFILE%\.doubi\`（即 `~/.doubi/`）下。

```
~/.doubi/
├── config.yml                  # 配置文件（设置页「保存设置」会写这里）
├── cookies/
│   ├── bilibili.txt            # B 站登录态（Netscape 格式）
│   └── douyin.txt              # 抖音登录态
├── doubi.db                    # SQLite：去重 + 历史
├── download_manifest.jsonl     # 下载清单（每行一条 JSON，便于外部工具消费）
└── logs/
    ├── doubi.log               # 主日志
    └── doubi-YYYYMMDD.log      # 按天滚动
```

下载完成的文件本身**不在这里**——在 `设置` → 下载目录字段指定的位置（默认 `%USERPROFILE%\Downloads\DouBi\`）。

> **0.3.3 之前的版本**把 `doubi.db` 和 `download_manifest.jsonl` 存成相对路径——从开始菜单启动 GUI 时会落在安装目录里，重装就全丢。**0.3.3 起**改成都在 `~/.doubi/`，卸载安装版时这目录默认**保留**，重装后配置与登录态还在。
>
> 升级到 0.3.3 的老用户首次启动时，程序会自动把旧的 `./var/doubi.db` / `./var/download_manifest.jsonl` 搬到 `~/.doubi/`，**目标位置已存在时绝不覆盖**（放弃迁移，直接用新路径继续跑——覆盖等于删掉你的历史）。

## 10. 异常处理

### 10.1 程序异常不会闪退

Qt 槽 / asyncio 任务里未捕获的异常会落完整 traceback 到 `~/.doubi/logs/` 里的日志，**不会直接消失进程**。GUI 上也会弹一个 InfoBar 提示——但错误堆栈要看日志。

### 10.2 下载失败

三种处理：

1. **网络问题**（超时 / 断流）：先暂停再继续，程序会重试
2. **画质被平台拒绝**：去设置 → 登录对应平台；登录后还能拿到高清画质
3. **真解析不到**：看 `~/.doubi/logs/` 里的最近日志，把 traceback 发给作者

### 10.3 找不到下载的文件

- 检查设置页「下载目录」字段——程序是按这个字段落盘的
- 检查目录模板和文件名字段是不是有 `{author}` / `{title}` 这种动态字段——可能和预期位置不一样
- 「历史」页能找到全部下载记录，点击能看到落盘路径

### 10.4 想给作者发日志

`~/.doubi/logs/` 整个目录 + 你的 `~/.doubi/config.yml`（**先脱敏**：删掉任何代理地址 / 自定义 token）打包发给作者即可。

## 11. 卸载

### 通过「控制面板 → 卸载程序」卸载安装版

- 程序文件全部清空
- **快捷方式**（开始菜单 + 桌面）全部清空
- **`~/.doubi/` 默认保留**——配置、登录态、下载记录、下载的文件都在

**想完全清空**：

- 在卸载界面勾选「同时删除配置和下载记录」（具体选项以你卸载时的实际弹窗为准）
- 或者卸载完后手动删 `C:\Users\<你>\.doubi\`

### 想保留什么

| 想保留 | 不删 |
|---|---|
| 配置（主题 / 语言 / 下载目录 / 文件名模板） | `~/.doubi/config.yml` |
| 登录态（不用重新扫码） | `~/.doubi/cookies/` |
| 历史记录 | `~/.doubi/doubi.db` |
| 下载清单（每行一条 JSON） | `~/.doubi/download_manifest.jsonl` |
| 已下载的文件 | 设置 → 下载目录 下的所有文件 |

如果你是要**重装**而不是卸载，**重装不删这些**——下次启动程序时它们都还在。

### 便携版（onefile）没有「卸载」

直接删 `doubi-gui.exe` 文件就是全部——程序运行时会自解压到 `%TEMP%\_MEIxxxxx\`，下次启动会重新解压。

## FAQ

### Q：下载到一半程序崩了，任务会丢吗？

不会。任务在 `~/.doubi/doubi.db` 里持久化——重启程序后打开「下载」页，已完成的显示为「已完成」，未完成的可以「重试」。

### Q：下载到 0% 卡住？

通常三个原因：

1. **平台风控 / IP 限流**——稍等几分钟，或换代理
2. **登录态过期**——去设置 → 账号 → 重新扫码
3. **HLS 站点进度条不更新**——**正常现象**：外部工具不吐进度的话，0.3.1 起程序自带 1Hz 的文件系统 watchdog 兜底，能看到文件大小在涨；进度条最终会跳到接近 100% 后直接完成

### Q：下载完了找不到文件？

检查设置 → 下载目录。程序是按那字段落盘的，**不会默认下到「下载」文件夹**。

### Q：解析结果为空？

| 平台 | 原因 |
|---|---|
| 抖音 | 99% 是**未登录**——抖音搜索类接口需要 cookie。先去设置 → 账号登录 |
| B 站 | 9/10 是链接过期——`BV1xx` 在 B 站上有有效期，重新复制最新链接 |

### Q：视频下下来播放不了？

- **B 站 1080P 以上**画质：必须登录后才能拿到——见 [§4 登录](#4-登录抖音--b-站)
- 容器格式（如 `.m4s`）：设置 → 容器改成 `mp4` / `mkv`

### Q：B 站搜索 / 热榜 0 条结果？

去设置 → 账号确认 B 站**已登录**。B 站搜索 `wbi` 接口需要 cookie 才能返回结果，未登录时直接 `code=-101`。

### Q：启动后窗口不显示 / 闪退？

看 `~/.doubi/logs/doubi.log` 最近一条的 traceback。常见原因：

1. **首次启动时被杀毒拦了**——把 DouBi 加信任
2. **配置文件语法错误**——手动删 `~/.doubi/config.yml` 重启会恢复默认
3. **数据库版本过旧**——设置页 → 跳过数据库的勾上再启动，能临时绕开

### Q：关掉窗口后还在下载？

正常的——窗口关掉 ≠ 程序退出。程序最小化到托盘继续跑，下载不中断。想真退出走托盘菜单「退出」。详见 [§8 托盘](#8-托盘)。

### Q：怎么换下载目录而不丢旧任务？

去设置 → 下载目录改成新路径 → 点「保存设置」→ **旧任务在「历史」页里仍能找到**（数据库记录的是 URL，不是绝对路径）。新任务会下到新目录。

### Q：批量下 10 个视频，怎么不下整个队列？

下载页顶部的「全部暂停」只暂停**当前正在跑**的任务；不重新入队。如果想要「暂停队列」效果，单条点「暂停」即可。
